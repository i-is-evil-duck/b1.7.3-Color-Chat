### Minecraft Beta 1.7.3 Color chat plugin

Adds chat colors and ranks with in-game configuration commands.

Supports configurable groups (e.g. VIP+, MVP+++) with bracket and plus-sign color styling, per-player name colors, and per-player chat text colors. Ranks are displayed as `[<rank>] <name>: <message>`.

**Commands:** `/colorchat help`, `/colorchat reload`, `/colorchat role <player> <group>`, `/colorchat name <player> <color>`, `/colorchat chat <player> <color>`, `/colorchat clear <player>`  
**Alias:** `/cc`  
**Permission:** `colorchat.admin` (default: OP)
